Comment nous avons travaillé

Le site est statique : des pages HTML, une feuille de style et un peu de JavaScript, sans étape de construction. Il s'ouvre directement dans un navigateur, même sans serveur, et peut être publié sur GitHub Pages. Les graphiques sont dessinés avec la bibliothèque D3 ; leurs données sont fournies sous forme de fichiers JavaScript pour que le site fonctionne aussi en local.

Organisation du groupe

Nous nous sommes répartis en trois sous-groupes, chacun chargé de répondre à l'une des trois questions de notre problématique :

  1. sous-groupe 1 : quel est l'impact de la construction et de la mise en place des data centers ?
  2. sous-groupe 2 : que coûte une conversation avec l'IA à l'environnement ?
  3. sous-groupe 3 : quel est l'impact des différents modèles d'IA, et lequel vaut-il mieux utiliser ?

Dans un premier temps, chaque sous-groupe a fait ses recherches à partir des données proposées par le défi de l'Open Data University, puis les a complétées par d'autres sources d'information : rapports d'organismes publics, études et articles, cités dans les sources de chaque partie.

Outils

  • Google Docs, pour rédiger et partager nos textes ;
  • Excel, pour rassembler les données par pays ;
  • Claude Code, un assistant de programmation fondé sur l'IA, pour construire le site et les graphiques ;
  • GitHub, pour mettre le site en commun et le publier avec GitHub Pages.

Un projet étudiant

Site réalisé par un groupe d'étudiants : première année, IAD (école d'ingénieurs), 2026-2027.

Ce site est indépendant : il n'engage ni l'ADEME, ni data.gouv.fr.

Le défi

Réponse au défi « L'impact environnemental de l'IA générative », proposé par l'ADEME dans le cadre de l'Open Data University.

Données ouvertes publiques : data.gouv.fr
